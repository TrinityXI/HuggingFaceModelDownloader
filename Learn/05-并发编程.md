## 1. Goroutine 基础

### 1.1 什么是 Goroutine

Goroutine 是 Go 的轻量级线程，由 Go 运行时管理。

**基本语法：**

```go
go functionName(args)
```

**项目中的例子** (`main.go` 第 144-152 行)：

```go
go func() {
	select {
	case <-ch:
		cancel()
	case <-ctx.Done():
	}
	signal.Stop(ch)
}()
```

### 1.2 Goroutine vs 传统线程

| 特性 | Goroutine | 系统线程 |
|------|-----------|----------|
| 创建开销 | ~2KB | ~1-2MB |
| 切换成本 | 低 | 高 |
| 数量限制 | 数万到数百万 | 数千 |
| 调度 | Go 运行时 | OS 调度器 |

### 1.3 简单示例

```go
package main

import (
	"fmt"
	"time"
)

func sayHello(name string) {
	for i := 0; i < 3; i++ {
		time.Sleep(100 * time.Millisecond)
		fmt.Printf("Hello, %s! (%d)\n", name, i)
	}
}

func main() {
	// 启动 goroutine
	go sayHello("Alice")
	go sayHello("Bob")
	
	// 主 goroutine 等待
	time.Sleep(500 * time.Millisecond)
	fmt.Println("Done!")
}
```

## 2. Channel 通信

### 2.1 Channel 基础

Channel 是 Goroutine 之间通信的管道。

**创建 Channel：**

```go
ch := make(chan int)         // 无缓冲 channel
ch := make(chan int, 10)     // 有缓冲 channel (容量10)
```

**发送和接收：**

```go
ch <- value    // 发送到 channel
value := <-ch  // 从 channel 接收
```

### 2.2 无缓冲 Channel

**项目中的例子** (`hfdownloader/downloader.go` 第 180 行)：

```go
errCh := make(chan error, len(plan.Items))
```

**同步通信示例：**

```go
func worker(ch chan string) {
	ch <- "work done"  // 发送会阻塞，直到有接收者
}

func main() {
	ch := make(chan string)
	go worker(ch)
	result := <-ch  // 接收会阻塞，直到有发送者
	fmt.Println(result)
}
```

### 2.3 有缓冲 Channel

**项目中的例子** (`hfdownloader/downloader.go` 第 177 行)：

```go
type token struct{}
lim := make(chan token, cfg.MaxActiveDownloads)
```

**非阻塞发送示例：**

```go
ch := make(chan int, 3)
ch <- 1  // 不阻塞
ch <- 2  // 不阻塞
ch <- 3  // 不阻塞
// ch <- 4  // 会阻塞，因为缓冲区满了
```

### 2.4 关闭 Channel

```go
ch := make(chan int, 2)
ch <- 1
ch <- 2
close(ch)  // 关闭 channel

// 接收直到 channel 关闭
for v := range ch {
	fmt.Println(v)  // 输出 1, 2
}

// 检查 channel 是否关闭
v, ok := <-ch
if !ok {
	fmt.Println("Channel closed")
}
```

## 3. Select 语句

### 3.1 基本用法

Select 允许 Goroutine 等待多个通信操作。

**项目中的核心例子** (`hfdownloader/downloader.go` 第 191-197 行)：

```go
select {
case <-ctx.Done():
	break LOOP  // 取消信号
default:
	// 继续执行
}
```

### 3.2 完整 Select 示例

**在下载循环中** (`hfdownloader/downloader.go` 第 208-219 行)：

```go
// 获取并发槽位或取消
select {
case lim <- token{}:
	// 获得槽位，继续
case <-ctx.Done():
	break LOOP  // 取消下载
}
```

### 3.3 Select 多路复用

```go
func worker(ch1, ch2 <-chan int, quit <-chan bool) {
	for {
		select {
		case v := <-ch1:
			fmt.Println("From ch1:", v)
		case v := <-ch2:
			fmt.Println("From ch2:", v)
		case <-quit:
			fmt.Println("Quitting!")
			return
		default:
			// 所有 channel 都不可用时执行
			fmt.Println("Waiting...")
			time.Sleep(100 * time.Millisecond)
		}
	}
}
```

## 4. 项目中的并发下载实现

### 4.1 并发控制模式

**限制并发数** (`hfdownloader/downloader.go` 第 175-177 行)：

```go
// 并发限制器
type token struct{}
lim := make(chan token, cfg.MaxActiveDownloads)
```

**使用模式**：

```go
// 获取令牌（阻塞直到有空位）
select {
case lim <- token{}:
	// 获得了执行权限
case <-ctx.Done():
	// 被取消了
	return
}

// 执行任务
go func() {
	defer func() { <-lim }()  // 释放令牌
	
	// 实际工作...
}()
```

### 4.2 文件下载的并发结构

**完整流程** (`hfdownloader/downloader.go` 第 189-290 行)：

```go
LOOP:
for _, item := range plan.Items {
	// 1. 检查取消
	select {
	case <-ctx.Done():
		break LOOP
	default:
	}

	// 2. 获取并发槽位
	select {
	case lim <- token{}:
	case <-ctx.Done():
		break LOOP
	}

	// 3. 启动 goroutine 下载
	wg.Add(1)
	go func() {
		defer wg.Done()
		defer func() { <-lim }()  // 释放槽位
		
		// 下载文件...
	}()
}

// 4. 等待所有下载完成
wg.Wait()
```

### 4.3 关键组件解析

**WaitGroup - 等待 Goroutine 完成**：

```go
var wg sync.WaitGroup

for i := 0; i < 5; i++ {
	wg.Add(1)
	go func(id int) {
		defer wg.Done()
		fmt.Printf("Worker %d done\n", id)
	}(i)
}

wg.Wait()  // 等待所有 worker 完成
fmt.Println("All workers done!")
```

**错误收集**：

```go
errCh := make(chan error, len(plan.Items))

	if err := doWork(); err != nil {
		select {
		case errCh <- err:  // 发送错误
		default:  // channel 满了就丢弃
		}
	}
}()
```

## 5. Sync 包

### 5.1 sync.Mutex（互斥锁）

保护共享资源：

```go
type SafeCounter struct {
	mu    sync.Mutex
	count int
}

func (c *SafeCounter) Increment() {
	c.mu.Lock()
	defer c.mu.Unlock()
	c.count++
}

func (c *SafeCounter) Value() int {
	c.mu.Lock()
	defer c.mu.Unlock()
	return c.count
}
```

### 5.2 sync.RWMutex（读写锁）

允许多个读者或一个写者：

```go
type Cache struct {
	mu    sync.RWMutex
	items map[string]string
}

func (c *Cache) Get(key string) string {
	c.mu.RLock()  // 读锁
	defer c.mu.RUnlock()
	return c.items[key]
}

func (c *Cache) Set(key, value string) {
	c.mu.Lock()  // 写锁
	defer c.mu.Unlock()
	c.items[key] = value
}
```

### 5.3 sync.Map（并发安全的 Map）

**项目中的例子** (`hfdownloader/downloader.go` 第 183 行)：

```go
var skipOnce sync.Map

// 存储
skipOnce.LoadOrStore(finalRel, struct{}{})

// 检查是否存在
if _, loaded := skipOnce.LoadOrStore(key, struct{}{}); !loaded {
	// 第一次存储
}
```

**sync.Map 方法：**

```go
var m sync.Map

// 存储
m.Store("key", "value")

// 读取
value, ok := m.Load("key")

// 删除
m.Delete("key")

// 存储或读取
actual, loaded := m.LoadOrStore("key", "value")

// 读取并删除
value, loaded := m.LoadAndDelete("key")

// 遍历
m.Range(func(key, value interface{}) bool {
	fmt.Println(key, value)
	return true  // 继续遍历
})
```

### 5.4 sync.Once（单次执行）

确保函数只执行一次：

```go
var (
	instance *Singleton
	once     sync.Once
)

func GetInstance() *Singleton {
	once.Do(func() {
		instance = &Singleton{}
	})
	return instance
}
```

## 6. Context 和取消机制

### 6.1 Context 基础

**项目中的信号处理** (`main.go` 第 140-155 行)：

```go
func signalContext(parent context.Context) (context.Context, context.CancelFunc) {
	ctx, cancel := context.WithCancel(parent)
	ch := make(chan os.Signal, 1)
	signal.Notify(ch, os.Interrupt, syscall.SIGTERM)
	
	go func() {
		select {
		case <-ch:
			cancel()  // 收到信号，取消 context
		case <-ctx.Done():
		}
		signal.Stop(ch)
	}()
	
	return ctx, cancel
}
```

### 6.2 取消传播

**在下载中使用** (`hfdownloader/downloader.go` 第 220-222 行)：

```go
// 为每个文件创建子 context
fileCtx, fileCancel := context.WithCancel(ctx)
defer fileCancel()
```

**检查取消**：

```go
select {
case <-ctx.Done():
	return ctx.Err()  // 返回取消原因
default:
	// 继续工作
}
```

### 6.3 Context 类型

```go
// 1. 根 context
ctx := context.Background()
ctx := context.TODO()

// 2. 带取消的 context
ctx, cancel := context.WithCancel(parent)
defer cancel()

// 3. 带超时的 context
ctx, cancel := context.WithTimeout(parent, 5*time.Second)
defer cancel()

// 4. 带截止时间的 context
deadline := time.Now().Add(10 * time.Second)
ctx, cancel := context.WithDeadline(parent, deadline)
defer cancel()

// 5. 带值的 context
ctx := context.WithValue(parent, key, value)
```

## 7. 并发模式

### 7.1 Worker Pool（工人池）

**项目实现**：

```go
// 创建工人池
type token struct{}
pool := make(chan token, workerCount)

// 分配任务
for _, task := range tasks {
	// 获取工人
	pool <- token{}
	
	go func(t Task) {
		defer func() { <-pool }()
		processTask(t)
	}(task)
}
```

### 7.2 Fan-Out/Fan-In

**Fan-Out**：一个输入，多个处理器

```go
func fanOut(input <-chan int, n int) []<-chan int {
	outputs := make([]<-chan int, n)
	for i := 0; i < n; i++ {
		outputs[i] = worker(input)
	}
	return outputs
}

func worker(input <-chan int) <-chan int {
	output := make(chan int)
	go func() {
		defer close(output)
		for v := range input {
			output <- v * 2
		}
	}()
	return output
}
```

**Fan-In**：多个输入，一个输出

```go
func fanIn(channels ...<-chan int) <-chan int {
	output := make(chan int)
	var wg sync.WaitGroup
	
	for _, ch := range channels {
		wg.Add(1)
		go func(c <-chan int) {
			defer wg.Done()
			for v := range c {
				output <- v
			}
		}(ch)
	}
	
	go func() {
		wg.Wait()
		close(output)
	}()
	
	return output
}
```

### 7.3 Pipeline（流水线）

```go
// 阶段 1: 生成数字
func generator(nums ...int) <-chan int {
	out := make(chan int)
	go func() {
		defer close(out)
		for _, n := range nums {
			out <- n
		}
	}()
	return out
}

// 阶段 2: 平方
func square(in <-chan int) <-chan int {
	out := make(chan int)
	go func() {
		defer close(out)
		for n := range in {
			out <- n * n
		}
	}()
	return out
}

// 使用
nums := generator(1, 2, 3, 4, 5)
squares := square(nums)

for sq := range squares {
	fmt.Println(sq)
}
```

## 8. 常见并发陷阱

### 8.1 Goroutine 泄漏

**❌ 错误：忘记关闭 channel**

```go
func leak() <-chan int {
	ch := make(chan int)
	go func() {
		for i := 0; ; i++ {
			ch <- i  // 如果没有接收者，会永久阻塞
		}
	}()
	return ch
}
```

**✅ 正确：使用 context 取消**

```go
func noLeak(ctx context.Context) <-chan int {
	ch := make(chan int)
	go func() {
		defer close(ch)
		for i := 0; ; i++ {
			select {
			case ch <- i:
			case <-ctx.Done():
				return
			}
		}
	}()
	return ch
}
```

### 8.2 数据竞争

**❌ 错误：并发写**

```go
var counter int

for i := 0; i < 10; i++ {
	go func() {
		counter++  // 数据竞争！
	}()
}
```

**✅ 正确：使用互斥锁或原子操作**

```go
// 方法 1: Mutex
var (
	counter int
	mu      sync.Mutex
)

mu.Lock()
counter++
mu.Unlock()

// 方法 2: atomic
var counter int64
atomic.AddInt64(&counter, 1)
```

**项目中的例子** (`hfdownloader/downloader.go` 第 185-186 行)：

```go
var skippedCount int64
var downloadedCount int64

// 使用原子操作
atomic.AddInt64(&skippedCount, 1)
atomic.AddInt64(&downloadedCount, 1)
```

### 8.3 Range 循环变量陷阱

**❌ 错误**：

```go
for _, v := range values {
	go func() {
		fmt.Println(v)  // 可能打印最后一个值
	}()
}
```

**✅ 正确**：

```go
for _, v := range values {
	v := v  // 创建新变量
	go func() {
		fmt.Println(v)
	}()
}

// 或者传递参数
for _, v := range values {
	go func(val int) {
		fmt.Println(val)
	}(v)
}
```

## 11. 最佳实践

1. **始终处理 Goroutine 的退出**
   - 使用 context 传播取消信号
   - 确保 Goroutine 能正常结束

2. **避免 Goroutine 泄漏**
   - 确保 channel 接收者存在
   - 使用 defer 清理资源

3. **控制并发数量**
   - 使用 worker pool 模式
   - 避免创建无限 Goroutine

4. **保护共享状态**
   - 使用 Mutex 或原子操作
   - 优先使用 channel 通信

5. **错误处理**
   - 使用专门的 error channel
   - 不要忽略 Goroutine 中的错误

6. **优雅关闭**
   - 使用 WaitGroup 等待完成
   - 关闭 channel 通知结束
