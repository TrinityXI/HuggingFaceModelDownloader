# Go 语言学习路线图

基于 HuggingFaceModelDownloader 项目的实战学习指南

## 📚 学习目标

通过分析和理解这个真实的下载工具项目，掌握 Go 语言的核心概念和实战技巧。

## 🎯 学习路径

### 第一阶段：基础知识 (1-3天)

**01. [基础语法](./01-基础语法.md)**
- 变量声明与类型
- 基本数据类型
- 函数定义
- 控制流程
- 实例：从 `main.go` 学习基础语法

**02. [结构体与方法](./02-结构体与方法.md)**
- 结构体定义
- 方法接收者
- 指针与值
- 实例：`types.go` 中的结构体设计

**03. [包与模块](./03-包与模块.md)**
- 包的组织
- 导入机制
- go.mod 管理
- 实例：项目的包结构分析

### 第二阶段：进阶特性 (3-5天)

**04. [错误处理](./04-错误处理.md)**
- error 接口
- 错误检查模式
- 错误包装
- 实例：`downloader.go` 中的错误处理

**05. [并发编程](./05-并发编程.md)**
- Goroutines
- Channels
- sync 包
- 实例：并发下载实现

**06. [接口与多态](./06-接口与多态.md)**
- 接口定义
- 隐式实现
- 类型断言
- 实例：ProgressFunc 回调设计

### 第三阶段：标准库应用 (3-5天)

**07. [HTTP 客户端](./07-HTTP客户端.md)**
- net/http 包
- HTTP 请求与响应
- 客户端配置
- 实例：下载器的 HTTP 实现

**08. [文件操作](./08-文件操作.md)**
- 文件读写
- 路径操作
- 目录管理
- 实例：文件下载和断点续传

**09. [JSON 处理](./09-JSON处理.md)**
- encoding/json
- 序列化与反序列化
- 自定义 JSON 标签
- 实例：API 响应解析

### 第四阶段：工程实践 (2-3天)

**10. [命令行工具](./10-命令行工具.md)**
- Cobra 框架
- 参数解析
- 配置文件
- 实例：CLI 实现分析

**11. [上下文管理](./11-上下文管理.md)**
- context 包
- 取消机制
- 超时控制
- 实例：优雅的取消下载

**12. [实战技巧](./12-实战技巧.md)**
- 项目结构最佳实践
- 代码组织
- 性能优化
- 测试策略

## 🔥 学习方法建议

### 1. 边学边做
每个章节都包含：
- ✅ 概念讲解
- ✅ 项目实例
- ✅ 代码片段分析
- ✅ 练习题

### 2. 阅读顺序

**新手路线**（从零开始）：
```
01 → 02 → 03 → 04 → 06 → 07 → 08 → 09 → 05 → 10 → 11 → 12
```

**有经验路线**（其他语言转 Go）：
```
03 → 02 → 04 → 06 → 05 → 07/08/09 → 10/11 → 12
```

**项目驱动路线**（直接上手）：
```
01 → 03 → 阅读项目代码 → 按需查阅其他章节
```

### 3. 实践建议

- 📖 **阅读原始代码**：每章都会引用项目中的真实代码
- 🔍 **使用 IDE**：推荐 VSCode + Go 插件，可以跳转定义
- ✍️ **动手修改**：尝试修改项目代码，理解每个部分的作用
- 🎯 **完成练习**：每章末尾都有针对性练习

### 4. 调试技巧

```bash
# 查看变量类型
go run -gcflags="-m" main.go

# 运行单个文件
go run main.go

# 查看文档
go doc net/http

# 格式化代码
go fmt ./...
```

## 💡 学习小贴士

1. **不要死记硬背**
   - Go 的语法很简洁，理解概念比记忆更重要

2. **多看项目代码**
   - 本项目代码质量高，是学习的好材料

3. **遇到问题先查文档**
   ```bash
   go doc package.Function
   ```

4. **利用工具**
   - `go fmt` 自动格式化
   - `go vet` 静态检查
   - `go test` 运行测试

5. **加入社区**

   - [r/golang](https://reddit.com/r/golang)
