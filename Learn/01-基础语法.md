## 1. 包声明与导入

### 1.1 包声明

每个 Go 文件都以 `package` 声明开始：

```go
// main.go 第1行
package main
```

**规则：**
- `package main` 表示这是可执行程序的入口包
- 其他包名（如 `package hfdownloader`）用于库代码
- 一个目录下的所有 `.go` 文件必须属于同一个包

### 1.2 导入包

**标准库导入** (`main.go` 第 3-14 行)：

```go
import (
	"context"
	"fmt"
	"os"
	"os/signal"
	"strings"
	"syscall"
	
	"github.com/spf13/cobra"
	"github.com/bodaay/HuggingFaceModelDownloader/hfdownloader"
)
```

**导入方式：**

```go
// 单个导入
import "fmt"

// 多个导入（推荐）
import (
	"fmt"
	"os"
)

// 别名导入
import (
	customname "very/long/package/name"
)

// 仅初始化（不常用）
import _ "package/name"
```

**分组规则**（约定俗成）：
1. 标准库包
2. 第三方包
3. 项目内部包

## 2. 变量声明

### 2.1 声明方式

**方式一：var 声明** (`main.go` 第 24-31 行)：


**方式二：短变量声明** (`main.go` 第 35 行)：

**方式三：明确类型**：

**方式五：批量声明**：


## 4. 函数

### 4.1 函数定义

**基本格式** (`main.go` 第 19 行)：

```go
func main() {
	// 函数体
}
```

**带参数和返回值** (`main.go` 第 140 行)：

```go
func signalContext(parent context.Context) (context.Context, context.CancelFunc) {
	ctx, cancel := context.WithCancel(parent)
	// ...
	return ctx, cancel
}
```

**多返回值示例** (`hfdownloader/downloader.go`)：

```go
func validate(job Job, cfg Settings) error {
	if job.Repo == "" {
		return errors.New("missing repo")
	}
	return nil
}
```

### 4.2 函数签名解析

```go
func 函数名(参数名 参数类型, ...) (返回类型1, 返回类型2) {
	// 函数体
}
```

**实例分析：**

```go
func Download(
	ctx context.Context,        // 参数1: context
	job Job,                    // 参数2: Job 结构体
	cfg Settings,               // 参数3: Settings 结构体
	progress ProgressFunc       // 参数4: 函数类型
) error {                       // 返回: error 类型
	// ...
	return nil
}
```

### 4.3 命名返回值

```go
func divide(a, b int) (result int, err error) {
	if b == 0 {
		err = errors.New("division by zero")
		return  // 自动返回 result 和 err
	}
	result = a / b
	return  // 自动返回 result 和 err
}
```

### 4.4 可变参数

```go
func sum(numbers ...int) int {
	total := 0
	for _, num := range numbers {
		total += num
	}
	return total
}

// 调用
sum(1, 2, 3)       // 6
sum(1, 2, 3, 4, 5) // 15
```

### 5.2 循环 (for)

**传统 for 循环：**

```go
for i := 0; i < 10; i++ {
	fmt.Println(i)
}
```

**while 风格**（Go 没有 while 关键字）：

```go
i := 0
for i < 10 {
	fmt.Println(i)
	i++
}
```

**无限循环：**

```go
for {
	// 永远执行，需要 break 退出
	if someCondition {
		break
	}
}
```

**range 遍历** (`main.go` 第 99 行)：

```go
for _, f := range job.Filters {
	// 遍历切片
}
```

**项目中的例子** (`hfdownloader/downloader.go` 第 189 行)：

```go
LOOP:
for _, item := range plan.Items {
	select {
	case <-ctx.Done():
		break LOOP  // 跳出标记的循环
	default:
	}
	// ...
}
```

### 5.3 Switch 语句

**基本用法：**

```go
switch value {
case 1:
	fmt.Println("One")
case 2:
	fmt.Println("Two")
default:
	fmt.Println("Other")
}
```

**不带表达式的 switch**（类似 if-else-if）：

```go
switch {
case x < 0:
	fmt.Println("Negative")
case x == 0:
	fmt.Println("Zero")
default:
	fmt.Println("Positive")
}
```

**项目中的例子** (`hfdownloader/downloader.go` 第 540 行)：

```go
switch n.Type {
case "directory", "tree":
	// 处理目录
case "file", "blob":
	// 处理文件
default:
	// 其他类型
}
```

### 5.4 Defer 语句

`defer` 延迟执行，常用于资源清理：

**项目中的例子** (`hfdownloader/downloader.go` 第 512 行)：

```go
func walkTree(...) error {
	resp, err := httpc.Do(req)
	if err != nil {
		return err
	}
	defer resp.Body.Close()  // 函数返回时自动关闭
	
	// 处理响应...
}
```

**多个 defer 按 LIFO 顺序执行**：

```go
func example() {
	defer fmt.Println("First")
	defer fmt.Println("Second")
	defer fmt.Println("Third")
	// 输出顺序: Third, Second, First
}
```

## 10. 常见陷阱

### 10.1 短变量声明的作用域

```go
// ❌ 错误
if err := doSomething(); err != nil {
	return err
}
fmt.Println(err)  // 错误：err 未定义

// ✅ 正确
var err error
if err = doSomething(); err != nil {
	return err
}
fmt.Println(err)
```

### 10.2 切片的底层数组共享

```go
s1 := []int{1, 2, 3, 4, 5}
s2 := s1[1:3]  // [2, 3]
s2[0] = 999    // 修改 s2 会影响 s1
// s1 现在是 [1, 999, 3, 4, 5]
```

### 10.3 range 循环的值拷贝

```go
// ❌ 错误
for _, item := range items {
	go func() {
		fmt.Println(item)  // 所有 goroutine 可能打印同一个值
	}()
}

// ✅ 正确
for _, item := range items {
	item := item  // 创建新变量
	go func() {
		fmt.Println(item)
	}()
}
```

## 11. 代码风格

Go 有严格的代码格式规范：

```bash
# 自动格式化
go fmt ./...

# 或使用 gofmt
gofmt -w *.go
```

**命名约定：**
- 包名：小写，单个词
- 导出标识符：大写字母开头 (Public)
- 非导出标识符：小写字母开头 (private)
- 驼峰命名：`UserCount` 而不是 `user_count`
